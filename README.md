## Опис проєкту

Цей репозиторій містить спеціалізованого AI-агента, призначеного для автоматичної генерації, складання, тестування та перевірки кросплатформного проєкту "Hello World". Проєкт реалізовано з використанням **JavaScript**, системи збірки **npm scripts** та фреймворку для тестування **Jest**.
