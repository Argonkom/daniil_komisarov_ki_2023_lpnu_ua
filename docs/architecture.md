# Архітектура AI-агента

## Проблеми, які вирішує агент

Агент автоматизує рутинні процеси створення програмного проєкту: розгортання базової структури, налаштування інструментів для тестування (Jest) та створення CI/CD пайплайнів (GitHub Actions) для кросплатформної перевірки (Windows, Linux, macOS).

## Використовувані Skills (навички)

- **project-scaffold**: Створює мінімальний проєкт Hello World (JavaScript), README, структуру каталогів та `.gitignore`[cite: 7].
- **build-and-test**: Налаштовує систему складання (npm scripts) та створює юніт-тести за допомогою Jest[cite: 7].
- **github-actions**: Створює CI workflow (`ci.yml`) з матрицею для Windows, Linux та macOS[cite: 7].

## Доступні Commands (команди)

- **git-init**: Перевіряє репозиторій, створює/оновлює `.gitignore`, показує стан Git[cite: 7].
- **create-project**: Викликає skill `project-scaffold`[cite: 7].
- **create-build**: Викликає skill `build-and-test`[cite: 7].
- **create-actions**: Викликає skill `github-actions`[cite: 8].
- **check**: Перевіряє структуру, конфігурацію, складання, тести та YAML workflow без зміни проєкту[cite: 8].
- **init**: Оркестратор, що послідовно запускає всі вищезгадані команди[cite: 8].

## Передача даних між етапами

Команди виконуються послідовно. Результат роботи кожної команди (створені файли, оновлені конфігурації `package.json`) стає передумовою для наступного етапу. Наприклад, `create-actions` покладається на наявність налаштованих npm-скриптів, створених на етапі `create-build`.

## Обробка помилок оркестратором

У разі виникнення помилки на будь-якому з етапів (наприклад, збій конфігурації або непроходження тестів), оркестратор зупиняє подальше виконання сценарію та виводить повідомлення із зазначенням причини збою.
